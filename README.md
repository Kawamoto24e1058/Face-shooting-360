# Face360（仮）

全方向・ジャイロ操作のスマホWeb ARシューティング（PWA）。周囲に出てくる「自分の顔」を、逃げられる前に端末を回して狙い撃つ。制限時間内にステージを進め、各ステージのボスを倒す。

## ゲームの流れ（ステージ制＋制限時間）

- 全5ステージ。各ステージは制限時間（50〜70秒、ボス戦を含む）内に「雑魚を規定数倒す → ボスを倒す」でクリア（`core/stages.ts`）
- 反撃・ライフはない（360度を見回すゲームで、後ろからの攻撃には対処できないため）
- 雑魚は一定時間で逃げる。逃げられると残り時間 −2秒（コンボも切れる）。怒り顔は突進してきて、目の前まで来ると逃げる
- 時間切れで失敗（TIME UP）。そのステージから再挑戦できる
- ボス戦では他の的をすべて退場させ、ボスだけにする。プレイヤーが向いている方向に出現
- ボスの行動（`core/boss.ts`）：構え → 回転して裏の弱点を見せる → 子分を呼ぶ → 回り込み …を繰り返す。子分がいる間ボスはガード（`GUARD`、点もダメージも入らない）。体力が減ると速くなり、子分が増える
- クリア時の★：残り時間が半分以上で★3、4分の1以上で★2、それ未満は★1。クリアボーナス（★×1000＋残り秒×50）
- 次のステージの前に正面を合わせ直す（体ごと回ったあとのずれを直すため）
- 記録：ベストスコアと到達ステージ（localStorage）

## 現在の到達点

要件書の開発順序のうち **段階1（骨組み）・段階2（撃つ）・段階3（顔を入れる）** を実装済み（＝MVPの範囲）。

- カメラ映像（背面）を背景に、透明 canvas の Three.js を重ねる。カメラ不可・OFF 時は仮想の部屋
- `deviceorientation` → クォータニオンで 3DoF 視点。キャリブレーションした向きを正面にする相対方式、slerp で平滑化
- センサーが無い環境（PC）ではドラッグで視点操作、クリック／スペースで発射、R でリロード
- 全周＋上下への的配置（仰角 −60〜+75 度、真上・真下はレア的）、座りモード（前方 120 度）
- 画面外の的を示す矢印、出現音の空間定位（PannerNode）
- ヒットスキャン＋見た目の弾道。UV → ゾーンマスクで部位判定（輪郭外はすり抜け）
- 残弾 12・リロード 1.2 秒、弾種 3 種（通常／貫通／拡散）。的が落とすアイテムで切替
- 得点計算（部位・コンボ・距離・動的ボーナス・同部位減衰）、ステージクリア画面、リザルト
- インク飛沫・衝撃波・画面縁インク（顔は崩さない）、演出 OFF 設定、Wake Lock、PWA

### 顔の取り込み（段階3）

1. 撮影（`capture="user"`）または写真を選択。EXIF の向きを反映し、長辺 1280px に縮小
2. MediaPipe Face Landmarker（478点・ブレンドシェイプ）で検出。顔なし／複数／横向き／小さすぎ／暗すぎはエラーで撮り直しを促す
3. 両目が水平になるよう回転して輪郭で切り抜き、512×512 の透過テクスチャにする
4. ランドマークから部位マスク（額・目・鼻・口・頬・顎）を生成。確認画面で判定エリアを色分け表示できる
5. 「自分の顔です」に同意すると IndexedDB に保存（テクスチャ・マスク・ランドマーク・ブレンドシェイプ）。次回以降は再利用
6. タイトルの設定から「顔データを削除」で DB ごと消える

- WASM とモデルは `scripts/prepare-assets.mjs` が `public/mediapipe/` に用意する（`npm run dev` / `build` の前に自動実行）。自前ホストなので、画像もモデル取得も外部CDNに依存しない
- 顔を取り込まずに「サンプルの顔で遊ぶ」も可能（図形描画のダミー顔）
- ゾーンマスクは「R チャンネルに部位 ID を書いた画像」。ダミー顔と写真の顔で同じ判定コードを使う

### 立体の顔（お面メッシュ）

- 取り込み時のランドマーク（478点）から、MediaPipe の 468 点メッシュ（三角形 852 枚）で顔の表面を作る
- 正面から見た配置（x,y）と見た目（テクスチャ）は本人の写真のまま。奥行き（z）は MediaPipe の標準顔モデル（`face/canonical.ts`、`scripts/gen-canonical.mjs` で生成）を本人の大きさに合わせ、さらに 35% に浅くして使う（本人の推定値は混ぜない）。奥行きが深いと、角度がついたときに鼻が高く見えて本人に見えなくなるため。浅い「レリーフ」にして、立体感は陰影と首振りで出す
- 目と口の穴は中心点を足して塞ぎ、外周を後ろへ押し出して厚みのある「お面」にする（`face/mesh.ts`、純関数）
- 三角形の並びは `scripts/gen-tesselation.mjs` で MediaPipe から取り出して `face/tesselation.ts` に保存（プレイ中は MediaPipe 本体を読み込まない）
- 的は少し首を振り（左右8度・上下3度）、陰影（半球光＋カメラに付けた平行光）で立体感を出す。当たり判定は表面の UV からゾーンマスクを引く（側面・裏は部位なし）
- 確認画面で立体の顔を回して確認できる。立体化より前に保存した顔は平面のまま（撮り直すと立体になる）

### 装飾（`render/decor.ts`）

顔の後ろにフード（半球＋縁取り）を付けてキャラクターに見せ、頭の上のパーツで的の性格が見た目で分かるようにした。すべてコードで組み立てた自作パーツ（外部素材なし）で、当たり判定には使わない。

| 的 | フード | 頭のパーツ |
| --- | --- | --- |
| 真顔 | 青 | アンテナ |
| 笑顔（2発耐える） | 銀 | 騎士のトサカと耳当て |
| 驚き（速い） | 黄 | プロペラ（回転） |
| 怒り（突進） | 赤 | 角 |
| 目つぶり（一瞬弱点） | 水色 | ナイトキャップ |
| 口開け（口でアイテム） | 緑 | パーティー帽 |
| レア（真上・真下） | 金 | 天使の輪 |
| ボス | ピンク（光る＝弱点） | 王冠（回転） |

## 開発

```bash
npm install
npm run dev        # https でないと実機のカメラ・センサーは使えない（下記）
npm test           # 得点計算・弾・配置・ヒットスキャンの単体テスト
npm run build
```

- 開発時のみ `window.__debugAim()` / `__debugAimBoss()` で照準を合わせ、`__debugBoss()` でボス戦へ進められる（自動テスト用、本番ビルドには含まれない）
- 実機確認は Vercel / Cloudflare Pages のプレビュー URL（HTTPS）を使うのが簡単。
  ローカルで試す場合は `vite --host` に HTTPS（例: `@vitejs/plugin-basic-ssl`）を足すか、トンネル（cloudflared 等）を使う

## 要件書からの変更・補足

- **キャリブレーション**: `alpha` を直接引く代わりに、姿勢クォータニオンから求めた水平方位（ヨー）で補正している。縦持ち（beta≈90°）では alpha と gamma が連動して不安定になるため
- **コンボ倍率の上昇幅**: 「リロード開始でコンボが切れる」「12発マガジン」の組み合わせだと、上昇幅 0.2 では ×5 に届かない。1マガジン内で上限に届くよう 0.4 にした
- **同部位減衰**: 0.8 倍ずつの下限が未定のため、仮に 0.2 を下限にした
- **残弾 0 のとき**: 自動でリロードを開始する（ボタンでも可）
- **効果音**: 素材を使わず Web Audio で合成している。素材を入れる段階で Howler.js に置き換える想定
- **取り込みの順序**: 要件書では「顔の取り込み → 許可取得」。iOS ではセンサー許可をタップ内で取る必要があるため、確認画面の「この顔で遊ぶ」のタップで許可を取り、保存はその裏で行う
- **サンプル顔**: 顔を使いたくない人・動作確認用に、取り込みをスキップできるようにした

## 表情と的の性格（段階4）

立体の顔に表情ごとの変形（モーフターゲット）を事前計算しておき、プレイ中は重みを補間するだけにしている（`face/mesh.ts`）。
表情は点数の倍率には使わず、動き・耐久・弱点の出方にだけ反映する（`core/expressions.ts`）。

| 表情 | 変形 | 性格 |
| --- | --- | --- |
| 真顔 | なし（ときどきまばたき） | 標準 |
| 笑顔 | 口角・頬・下まぶたを上げる | 2発耐える |
| 驚き | 眉・上まぶたを上げ、口を開ける | 速く動き回る |
| 怒り | 眉頭を下げて寄せ、目を細め、口角を下げる | 突進してきて、目の前まで来ると逃げる |
| 目つぶり | まぶたを閉じる | 一瞬目を見開いた瞬間は、どこに当てても「目」扱い |
| 口開け | 下あごを下げる（口をパクパク） | 口に当てるとアイテムを必ず落とす |

- 口は「動かない写真の面」と「奥の暗い口の中」で作り、下あごが下がると口の中が見える
- 当たって耐えたときは目をつぶってちぢむ。顔は崩さない
- 出現する表情はウェーブが進むと増える。元写真の表情（ブレンドシェイプ）と同じものが少し出やすい（感情の判定や表示には使わない）

### ボス

- 自分の顔の大型版（怒り顔＋王冠）。裏（ピンクに光るフード）が弱点で4ダメージ（`WEAK!`）、表は1ダメージ
- 体力はステージごとに 12〜30。撃破で +5000 とステージクリア

## PWA

- `vite-plugin-pwa`：アプリ本体（JS/CSS/HTML/アイコン）を事前キャッシュし、オフラインでも起動・プレイできる
- MediaPipe の WASM・モデルは初回の顔取り込み時にキャッシュ（約16MB、事前キャッシュはしない）
- アイコン：PNG（192/512、maskable 512、apple-touch-icon 180）。`scripts/gen-icons.py` で再生成できる
- 更新はプレイ中に勝手に再読み込みしないよう、タイトル画面に「新しいバージョンがあります [更新]」を出して選んでもらう
- Android Chrome はタイトル画面の「ホーム画面に追加」ボタン、iOS Safari は「共有 → ホーム画面に追加」の案内を表示
- 縦持ち・全画面（`display: fullscreen`、iOS はステータスバーを透過）
